Identitas Trigonometri Lengkap

1. Pengertian & Kegunaan

Identitas trigonometri adalah persamaan yang memuat fungsi trigonometri dan berlaku untuk setiap nilai sudut yang terdefinisi. Berbeda dengan persamaan trigonometri yang hanya benar pada sudut-sudut tertentu, identitas selalu benar.
Identitas digunakan untuk:
  • Menyederhanakan bentuk trigonometri yang panjang.
  • Membuktikan dua bentuk trigonometri sama.
  • Menghitung nilai fungsi trigonometri sudut tidak istimewa.
  • Menyelesaikan persamaan trigonometri dan limit fungsi trigonometri.
\[ \sin^2 x + \cos^2 x = 1 \]
Strategi umum
Ubah semua fungsi menjadi sinus dan kosinus, lalu sederhanakan. Jika menemui bentuk kuadrat, manfaatkan identitas Pythagoras.

2. Identitas Dasar

2.1 Identitas Resiprokal (Kebalikan)

\[ \csc x = \frac{1}{\sin x}, \qquad \sec x = \frac{1}{\cos x}, \qquad \cot x = \frac{1}{\tan x} \]

2.2 Identitas Perbandingan

\[ \tan x = \frac{\sin x}{\cos x}, \qquad \cot x = \frac{\cos x}{\sin x} \]

2.3 Identitas Pythagoras

\[ \sin^2 x + \cos^2 x = 1 \] \[ 1 + \tan^2 x = \sec^2 x \] \[ 1 + \cot^2 x = \csc^2 x \]
Asal rumus kedua dan ketiga
Bagi \(\sin^2 x + \cos^2 x = 1\) dengan \(\cos^2 x\): \[ \frac{\sin^2 x}{\cos^2 x} + 1 = \frac{1}{\cos^2 x} \;\Rightarrow\; \tan^2 x + 1 = \sec^2 x \] Bagi dengan \(\sin^2 x\) menghasilkan \(1 + \cot^2 x = \csc^2 x\).

3. Identitas Sudut Negatif & Relasi Sudut

\[ \sin(-x) = -\sin x, \qquad \cos(-x) = \cos x, \qquad \tan(-x) = -\tan x \]
Relasi sudut dalam berbagai kuadran:
Sudut \(\sin\) \(\cos\) \(\tan\)
\(90^\circ - x\) \(\cos x\) \(\sin x\) \(\cot x\)
\(90^\circ + x\) \(\cos x\) \(-\sin x\) \(-\cot x\)
\(180^\circ - x\) \(\sin x\) \(-\cos x\) \(-\tan x\)
\(180^\circ + x\) \(-\sin x\) \(-\cos x\) \(\tan x\)
\(270^\circ - x\) \(-\cos x\) \(-\sin x\) \(\cot x\)
\(270^\circ + x\) \(-\cos x\) \(\sin x\) \(-\cot x\)
\(360^\circ - x\) \(-\sin x\) \(\cos x\) \(-\tan x\)
Pola tanda
Tentukan tanda berdasarkan kuadran sudut asal, lalu gunakan sudut acuan. Ingat ASTC: kuadran I semua positif, kuadran II hanya sinus, kuadran III hanya tangen, kuadran IV hanya kosinus.

4. Identitas Jumlah & Selisih Dua Sudut

\[ \sin(A + B) = \sin A\cos B + \cos A\sin B \] \[ \sin(A - B) = \sin A\cos B - \cos A\sin B \] \[ \cos(A + B) = \cos A\cos B - \sin A\sin B \] \[ \cos(A - B) = \cos A\cos B + \sin A\sin B \] \[ \tan(A + B) = \frac{\tan A + \tan B}{1 - \tan A\tan B} \] \[ \tan(A - B) = \frac{\tan A - \tan B}{1 + \tan A\tan B} \]
Ingat pola tanda
Untuk sinus: tanda dalam kurung sama dengan tanda di ruas kanan.
Untuk kosinus: tanda dalam kurung berlawanan dengan tanda di ruas kanan.
Untuk tangen: penyebut memakai tanda yang berlawanan dengan pembilang.

5. Identitas Sudut Rangkap

\[ \sin 2A = 2\sin A\cos A \] \[ \cos 2A = \cos^2 A - \sin^2 A = 2\cos^2 A - 1 = 1 - 2\sin^2 A \] \[ \tan 2A = \frac{2\tan A}{1 - \tan^2 A} \]
Asal rumus
Substitusikan \(B = A\) pada rumus jumlah dua sudut: \[ \sin(A + A) = \sin A\cos A + \cos A\sin A = 2\sin A\cos A \] \[ \cos(A + A) = \cos A\cos A - \sin A\sin A = \cos^2 A - \sin^2 A \] Bentuk lain \(\cos 2A\) diperoleh dengan mengganti \(\cos^2 A = 1 - \sin^2 A\) atau \(\sin^2 A = 1 - \cos^2 A\).
Pilih bentuk yang sesuai
Jika diketahui \(\sin A\), gunakan \(\cos 2A = 1 - 2\sin^2 A\).
Jika diketahui \(\cos A\), gunakan \(\cos 2A = 2\cos^2 A - 1\).

6. Identitas Sudut Setengah

\[ \sin\frac{A}{2} = \pm\sqrt{\frac{1 - \cos A}{2}} \] \[ \cos\frac{A}{2} = \pm\sqrt{\frac{1 + \cos A}{2}} \] \[ \tan\frac{A}{2} = \frac{\sin A}{1 + \cos A} = \frac{1 - \cos A}{\sin A} \]
Menentukan tanda
Tanda \(\pm\) dipilih berdasarkan kuadran sudut \(\tfrac{A}{2}\), bukan kuadran \(A\). Jika \(A\) diketahui berada pada interval tertentu, tentukan lebih dulu interval \(\tfrac{A}{2}\).

7. Perkalian ke Jumlah/Selisih & Sebaliknya

7.1 Perkalian ke Jumlah/Selisih

\[ 2\sin A\cos B = \sin(A + B) + \sin(A - B) \] \[ 2\cos A\sin B = \sin(A + B) - \sin(A - B) \] \[ 2\cos A\cos B = \cos(A + B) + \cos(A - B) \] \[ 2\sin A\sin B = \cos(A - B) - \cos(A + B) \]
Perhatikan tanda terakhir
Untuk \(2\sin A\sin B\), hasilnya adalah \(\cos(A-B) - \cos(A+B)\), yaitu selisih dengan \(\cos(A+B)\) di belakang. Ini berbeda dari tiga rumus lainnya yang memakai tanda tambah atau selisih langsung.

7.2 Jumlah/Selisih ke Perkalian

\[ \sin A + \sin B = 2\sin\frac{A+B}{2}\cos\frac{A-B}{2} \] \[ \sin A - \sin B = 2\cos\frac{A+B}{2}\sin\frac{A-B}{2} \] \[ \cos A + \cos B = 2\cos\frac{A+B}{2}\cos\frac{A-B}{2} \] \[ \cos A - \cos B = -2\sin\frac{A+B}{2}\sin\frac{A-B}{2} \]

8. Identitas pada Segitiga & Identitas Bersyarat

Jika \(A, B, C\) adalah sudut-sudut segitiga, maka \(A + B + C = 180^\circ\). Akibatnya:
\[ \sin(A + B) = \sin C, \qquad \cos(A + B) = -\cos C, \qquad \tan(A + B) = -\tan C \] \[ \sin\frac{A}{2} = \cos\frac{B + C}{2}, \qquad \cos\frac{A}{2} = \sin\frac{B + C}{2} \]
Identitas bersyarat berlaku hanya jika syarat sudutnya dipenuhi. Contoh:
\[ A + B = 45^\circ \;\Rightarrow\; (1 + \tan A)(1 + \tan B) = 2 \] \[ A + B = 90^\circ \;\Rightarrow\; \sin^2 A + \sin^2 B = 1 \]

9. Ringkasan Rumus

KelompokRumus Penting
Dasar \(\sin^2 x + \cos^2 x = 1\); \(\tan x = \dfrac{\sin x}{\cos x}\)
Pythagoras lanjutan \(1 + \tan^2 x = \sec^2 x\); \(1 + \cot^2 x = \csc^2 x\)
Jumlah/selisih \(\sin(A \pm B)\), \(\cos(A \pm B)\), \(\tan(A \pm B)\)
Sudut rangkap \(\sin 2A = 2\sin A\cos A\); \(\cos 2A = 1 - 2\sin^2 A = 2\cos^2 A - 1\)
Sudut setengah \(\sin\frac{A}{2} = \pm\sqrt{\frac{1-\cos A}{2}}\); \(\cos\frac{A}{2} = \pm\sqrt{\frac{1+\cos A}{2}}\)
Perkalian ke jumlah \(2\sin A\cos B = \sin(A+B) + \sin(A-B)\)
Jumlah ke perkalian \(\sin A + \sin B = 2\sin\frac{A+B}{2}\cos\frac{A-B}{2}\)

10. Tips & Kesalahan Umum

Tips mengerjakan soal identitas
  1. Ubah ke sin dan cos terlebih dahulu jika bentuknya memuat tangen, sekon, atau kosekan.
  2. Kerjakan ruas yang lebih rumit sampai bentuknya sama dengan ruas lain.
  3. Cari bentuk kuadrat lalu gunakan \(\sin^2 x + \cos^2 x = 1\).
  4. Jika muncul \(2x\), pikirkan sudut rangkap; jika muncul \(\tfrac{x}{2}\), pikirkan sudut setengah.
  5. Jika muncul jumlah/selisih sinus atau kosinus, gunakan rumus jumlah ke perkalian.
  6. Untuk soal bergantung sudut lain, gunakan relasi sudut (mis. \(\sin(180^\circ - x) = \sin x\)).
Kesalahan yang sering terjadi
  • Menulis \(\sin(A + B) = \sin A + \sin B\). Ini salah.
  • Menulis \(\cos 2A = 2\cos A\) atau \(\sin 2A = 2\sin A\). Ini salah.
  • Tertukar antara \(\cos(A - B)\) dan \(\cos(A + B)\) pada rumus jumlah kosinus.
  • Lupa tanda negatif pada \(\cos A - \cos B\) dan pada \(2\sin A\sin B\).
  • Salah memilih tanda \(\pm\) pada sudut setengah karena tidak memeriksa kuadran \(\tfrac{A}{2}\).
  • Membagi dengan \(\sin x\) atau \(\cos x\) tanpa memeriksa kemungkinan nilainya \(0\).
Cek cepat hasil
Uji dengan sudut sederhana, misalnya \(x = 30^\circ\) atau \(A = B = 45^\circ\). Jika kedua ruas identitas memberi nilai yang sama, hasil penyederhanaan kemungkinan besar benar.
